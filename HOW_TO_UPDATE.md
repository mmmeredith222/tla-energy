# How to Update the TLA Energy Website

1. Edit files (index.html, style.css, images)
2. Save changes

3. Publish:
   git add .
   git commit -m "Describe change"
   git push

4. View live site:
   https://mmmeredith222.github.io/tla-energy/

5. Hard refresh:
   Cmd + Shift + R

If changes don’t appear:
- Wait 1–2 minutes
- Use Incognito window
- Add ?v=2 to URL
